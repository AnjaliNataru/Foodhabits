FOOD HABITS – NUTRITION CALCULATOR
===================================

Files:
- index.html  : Website structure and content
- style.css   : Website design and responsive layout
- script.js   : Nutrition calculator logic

HOW TO OPEN:
1. Extract this ZIP file.
2. Open index.html in Chrome or another browser.

HOW TO PUBLISH ON GITHUB PAGES:
1. Sign in to GitHub and create a public repository named food-habits.
2. Upload index.html, style.css and script.js to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for deployment. Your website URL will look like:
   https://YOUR-USERNAME.github.io/food-habits/

IMPORTANT:
These are recreated, editable source files based on the Food Habits and Nutrition
Calculator project details discussed in chat. They are not a download of the
original Tiiny.host site's private source files. Nutrition values are approximate
educational examples and should be checked before being used for health decisions.
